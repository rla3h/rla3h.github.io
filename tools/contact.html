GitHub 이슈는 공개 게시판입니다. 이름, 연락처, 성적 같은 개인정보는 적지 말아 주세요.

이런 내용을 알려 주세요

  • 오류 제보: 어떤 도구에서, 어떤 값을 넣었을 때, 어떤 결과가 나왔는지
  • 계산 기준 문의: 학교 안내와 결과가 다를 때, 학교에서 안내한 기준
  • 기능 제안: 있으면 좋겠다고 생각하는 학생용 도구나 가이드 주제
